# Actual Knowledge claim HTTP boundary

Incomplete WIP. The old standalone adapter POSTed /v1/claims/status, an adapter-only convention absent from E07; its 404 looked like an unknown claim. The replacement reads GET /v1/claims/:id and maps the factual/editorial assessment tracks of the actual claim dossier. An exact positive cited E07 claim edition is required; a newer or different returned edition denies, never silently substitutes. Withdrawn/superseded claims are blocked; either assessment needing re-verification is stale. Missing required flags/tracks or unknown enum values deny, never default to usable.

One captured service credential is required per request and must match the caller tenant/project/purpose before transport. A token callback supports later rotation; the receiving E07 verifies signatures. This service credential does not delegate the original human identity, compartments or current source/use permission. Hosts must authorize the caller and select appropriately restricted service credentials. No caller capability is forwarded as authority.

The owning HTTP implementation has a monotonic 100..120000ms credential/transport/body/parse budget, 512KiB/4096 chunks, fatal UTF8, independent chunk copies, signal closure and best-effort late-body cancellation. Begun remote work cannot be undone or called rollback/quiescence. Model adapters and output/export/publication policies are separate and unchanged. No live provider, mail, publication, paid infrastructure or private research import is authorized.

Five focused synthetic groups pass; current typecheck/build, real pinned E07 integration, package exports and final-head CI remain separately qualified. No full local PostgreSQL/current rights/distributed fence/browser/assistive-technology/live acceptance claim. The original approved 15-engine/122-task public design is copied byte-for-byte into docs/approved-design and owning task/dependency IDs recorded in registry/prs.json. Existing service source is reused; no new SQL, foreign DB access or persistence adapter is added. Operational PAM remains stopped at its authorized foundation.
