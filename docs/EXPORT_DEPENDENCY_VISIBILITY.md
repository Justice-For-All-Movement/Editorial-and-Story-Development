# Private export dependency visibility

`exportView` now requires the caller's current compartment visibility for the referenced editorial project, every credited collaborator and every selected viewpoint. It no longer uses system reads for project labels/publishing identity, contributor names/credit lines or viewpoint labels/attribution. A missing or inaccessible required object fails the whole export with the existing generic `not_found`, rather than dropping a credit/viewpoint or borrowing another revision. These own reads precede current external fact metadata callbacks, use decisions and the export idempotency cache.

The public document's visibility alone is insufficient to disclose the current metadata of its internal dependencies. New exports and identical cached acknowledgements both pass these checks. Denied requests preserve existing exports, document/source revisions, audit/event history and original acknowledgements; authorized identical replay returns that original content without another export effect. Nothing is deleted or repaired to bypass a guard.

## Boundaries and remaining work

This is scoped current own-engine dependency visibility, not original-human authentication/current membership, complete recursive E09 source mapping, historical permission attestation, source truth, or a final whole-basis check after object I/O. The synthetic use-decision fixture only isolates visibility; actual E11/other-engine chains run separately and do not establish combined human/rights qualification. Current metadata is loaded according to existing project/viewpoint rules; no immutable manifest/history is rewritten and no external latest edition is substituted.

Post-storage whole-source/own-visibility revalidation, recursive dependency currentness and retained orphan/unknown-outcome reconciliation remain separate. PR6's final optional host authorization check continues to withhold responses after its denial while preserving committed history. SQL and object storage are not a distributed transaction, unknown is not rollback/quiescence, sequential checks are not distributed fencing, and returned copies cannot be revoked. Host human/delegation, PKI, TLS, lifecycle, callback CPU/heap/deadlines, driver and browser/AT acceptance remain unqualified. No new schema, adapter, credentials, send, public release, payment, paid infrastructure or operational PAM.
