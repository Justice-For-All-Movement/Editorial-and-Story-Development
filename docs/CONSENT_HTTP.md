The port evaluates a captured bounded request only: no actual use recording, publication, sends, payment or execution. Every call evaluates afresh; no idempotency key, automatic retry or stored-decision replay is exposed. A lost response may leave an upstream decision/audit committed; unavailable is not rollback or proof of stopped work.
