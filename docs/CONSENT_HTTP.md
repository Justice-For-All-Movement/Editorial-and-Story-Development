# Standalone Consent decision HTTP port

Optional CONSENT_URL and CONSENT_TOKEN_FILE wire Editorial to the actual E11 POST /v1/use-decisions route. The port evaluates a captured bounded request only: no actual use recording, publication, sends, payment or execution. Every call evaluates afresh; no idempotency key, automatic retry or stored-decision replay is exposed. A lost response may leave an upstream decision/audit committed; unavailable is not rollback or proof of stopped work.

One service credential must match the captured caller tenant/project/purpose; its compartments cannot exceed the caller snapshot. Decoded claims constrain credential selection, not signature authentication, original-human delegation or current source rights; E11 verifies signatures. Subjects/action/purpose/audience/territory/destination are copied and validated before credential work (200 subjects, 64KiB whole request). Unknown fields, including override/idempotency controls, deny. A separate literal decision response maps allow/deny/review without upgrading review. Required arrays and finite timestamp are checked.
